# GS Comunicação Visual

Site estático da GS Comunicação Visual com catálogo de serviços, galeria de trabalhos realizados e pedidos de orçamento pelo WhatsApp.

## Como publicar no GitHub Pages

1. Extraia o ZIP e envie os arquivos extraídos para um repositório do GitHub. Deixe `index.html`, `styles.css`, `galeria.js`, `.nojekyll` e a pasta `assets/` na raiz do repositório.
2. No repositório, abra **Settings → Pages**. Em **Source**, escolha **Deploy from a branch**.
3. Selecione o branch que recebeu os arquivos (por exemplo, `main`) e a pasta **/(root)**. Clique em **Save**.
4. Abra o endereço que aparece em **Settings → Pages** quando a publicação estiver pronta.

[Documentação oficial do GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

Para testar antes de publicar, abra `index.html` no navegador após extrair o ZIP.

As fotos dos trabalhos estão na pasta `assets/trabalhos/`.
